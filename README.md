# แผนเข้ามหาวิทยาลัย TCAS70
เว็บแอปช่วยวางแผนเข้ามหาวิทยาลัย: กรอกเกรด/คำนวณ GPAX แล้วเทียบกับเกณฑ์ของแต่ละคณะ เลือกมหาวิทยาลัยและคณะได้ บันทึกเป้าหมายและเช็กลิสต์ในเครื่อง (localStorage)

## โครงสร้าง
- index.html: หน้าหลัก
- css/: theme.css (สี/โหมดมืด), base.css (พื้นฐาน), layout.css (แถบแท็บ), components.css (การ์ด ปุ่ม ฟอร์ม)
- js/data/: faculties.js (คณะและความยาก), universities.js (รายชื่อมหาวิทยาลัย), programs.js (สร้างรายการหลักสูตร), constants.js (เกรด รอบ TCAS งานที่ต้องทำ)
- js/core/: storage.js (บันทึก/โหลด), calc.js (คำนวณ GPAX และเทียบเกณฑ์)
- js/features/: grade.js, match.js, importer.js, home.js, goals.js, plan.js (แต่ละหน้า/ฟีเจอร์)
- js/app.js (สลับแท็บ), events.js (อีเวนต์), main.js (เริ่มแอป)
- tools/bundle.py: รวมเป็นไฟล์เดียวสำหรับทดลอง

หมายเหตุ: เกณฑ์ใน data เป็นค่าประมาณการ ไม่ใช่ข้อมูลทางการ ใช้ปุ่มนำเข้าในหน้าจับคู่คณะเพื่อแทนด้วยข้อมูลจริง
